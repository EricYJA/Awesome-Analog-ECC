# Awesome Analog ECC

A small BibTeX collection for analog error-correcting codes, analog and
in-memory computing, and related mathematical background.

This repository is meant to provide a convenient starting bibliography for
research on analog ECC, defect-tolerant crossbar computation, memristive
computing, and supporting topics such as frame theory, linear algebra, and
optimization.

## File Tree

```text
.
```

## Files

- `analog-ecc.bib` contains the main analog error-correcting code references.
  It includes foundational analog ECC papers, crossbar-oriented ECC work,
  multiple-error correction, recent code constructions, and related arXiv
  preprints.

- `analog-computing.bib` contains background references on analog,
  neuromorphic, and in-memory computing hardware. Topics include memristive
  systems, phase-change memory chips, dot-product engines, edge learning, and
  fault-tolerant crossbar architectures.

- `related-literature.bib` contains supporting literature that is useful for
  studying or developing analog ECC methods. It currently includes references
  on frame theory, finite tight frames, linear algebra, optimization on
  manifolds, and Bayesian optimization.

## Notes

When adding new references, keep analog ECC theory papers in
`analog-ecc.bib`, hardware and system papers in `analog-computing.bib`, and
general background references in `related-literature.bib`.
