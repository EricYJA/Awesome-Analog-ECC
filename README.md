# Awesome Analog ECC

A small BibTeX bibliography collection for analog error-correcting codes, analog/in-memory computing, frame theory, and related background literature.

## Files

`analog-ecc.bib` contains core analog error-correcting code references, including foundational papers, corrections, defect-tolerant crossbar work, multi-error correction, design/analysis work, and recent arXiv preprints.

`analog-computing.bib` contains references on analog and in-memory computing hardware, including analog neural processors, memristive systems, phase-change memory chips, edge learning, and fault-tolerant crossbar architectures.

`frame-theory.bib` contains frame theory references, currently covering structured tight frames and finite tight frame fundamentals.

`related-literature.bib` contains supporting background literature, including linear algebra, optimization on manifolds, Bayesian optimization, and coding theory references.

Each file contains BibTeX entries that can be imported directly into LaTeX, BibTeX, or reference-management workflows.
